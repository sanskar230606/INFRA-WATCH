# Project Tech Stack

| Technology / Tool | Purpose in Project |
| :--- | :--- |
| **React 19** | Core frontend framework for building reactive components, state management, and user interfaces. |
| **Vite** | Build tool and local development server providing instant module reloading and production bundling. |
| **Native SVG (Scalable Vector Graphics)** | Powers all data graphs and charts (the Budget vs Time S-Curve trajectory, milestone points, coordinate grids, and circular progress rings) without requiring third-party charting libraries. |
| **HTML5 Canvas (2D)** | Powers the interactive 3D particle field background, handling physics simulation, depth parallax, and mouse attraction at 60 FPS. |
| **Vanilla CSS3** | Custom styling, design tokens, dual-theme system (Dark/Light), glassmorphism effects, and responsive grid layouts. |
| **Lucide React** | Icon library providing icons used across cards, badges, buttons, and navigation bars. |
| **Google Fonts** | Typography suite loading Inter (UI text), JetBrains Mono (metrics and project codes), and Space Grotesk (headings). |
| **HTML5 History API** | Client-side routing and page navigation between the home dashboard and individual project details pages. |
| **Browser Web APIs** | - **Local Storage**: Persisting theme and accessibility preferences.<br>- **Intersection Observer**: Pausing background animations when scrolled off-screen.<br>- **Clipboard & Print APIs**: Copying project links and generating downloadable PDF dossiers. |
| **Oxlint** | High-speed static analysis and linting to maintain code quality. |
